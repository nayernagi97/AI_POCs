# Build Interactive Agents with Generative UI

## Purpose

This workspace tracks my learning for the course "Build Interactive Agents with
Generative UI". It keeps course code, lecture notes, and working context in one
predictable place inside the `POCs/` directory.

## Workspace Structure

```text
build-interactive-agents-with-generative-ui/
├── README.md
├── code/
└── notes/
```

- `code/`: Store all source files, experiments, exercises, and prototypes from
  the course.
- `notes/`: Store lecture notes, summaries, takeaways, and lesson-specific
  observations.

## How To Use This Workspace

1. Add all code created while following the course under `code/`.
2. Add one note file per lesson or topic under `notes/`.
3. Update this README if the course structure changes or if new conventions are
   needed.

## Returning Later

Start with this README to understand the workspace layout, then open `notes/`
for lesson context and `code/` for implementation artifacts.
