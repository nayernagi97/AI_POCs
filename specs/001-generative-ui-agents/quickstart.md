# Quickstart: Generative UI Course Workspace

## Goal

Create and verify a dedicated course workspace under `POCs/` for "Build
Interactive Agents with Generative UI".

## Steps

1. Create the directory `POCs/build-interactive-agents-with-generative-ui/`.
2. Inside that directory, create:
   - `README.md`
   - `code/`
   - `notes/`
3. Add placeholder files to keep empty folders visible in Git if needed.
4. Write the README so it includes:
   - the course title
   - the purpose of the workspace
   - where code belongs
   - where lecture notes belong
5. Verify the learner can identify the correct location for new code and notes
   within 2 minutes without reading any unrelated repository documentation.

## Validation

1. Open `POCs/` and confirm there is exactly one course workspace for this
   course.
2. Open the new workspace and confirm `README.md`, `code/`, and `notes/`
   exist.
3. Read the README and confirm it explains the course and folder layout.
4. Confirm future notes can be added under `notes/` without renaming the
   workspace or restructuring the root.
